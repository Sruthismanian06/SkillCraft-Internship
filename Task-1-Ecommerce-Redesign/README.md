# Task 1 — E-commerce App Redesign

## 🎯 Objective
Improve usability, navigation, and product discovery experience in an e-commerce application.

---

## 🧠 UX Problem
- Poor navigation structure  
- Low product discoverability  
- Weak visual hierarchy  
- High cognitive load during browsing  

---

## 🎨 Solution
- Redesigned app layout for better clarity and structure  
- Improved product browsing flow and user navigation  
- Enhanced visual hierarchy for faster scanning  
- Simplified interface to reduce cognitive load  

---

## 🛠️ UX Skills Applied
User Flow Design · Information Architecture · Visual Hierarchy · Usability Improvement · UI Redesign
