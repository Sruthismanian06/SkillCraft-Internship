# Zomato Redesign – Modern Food Ordering Experience 🍕

A modern UI/UX redesign concept for Zomato focused on improving food discovery, restaurant browsing, menu interaction, and checkout experience through a cleaner and more intuitive interface.

---

## 📌 Project Overview

This project redesigns the food ordering experience by simplifying navigation, improving visual hierarchy, and creating a more consistent user flow from homepage to checkout.

The redesign focuses on:
- Cleaner homepage experience
- Better restaurant discovery
- Improved menu browsing
- Simplified checkout flow
- Modern and consistent UI system

---

## 🎯 Objectives

- Improve usability and navigation
- Create a modern food ordering experience
- Reduce visual clutter
- Improve checkout experience
- Build a consistent design system
- Design an end-to-end ordering flow

## ♻️ Reusable Design System

To maintain consistency across the project, reusable components and templates were created and reused throughout the design system.

This includes:
- Restaurant cards
- Food menu cards
- Buttons
- Checkout components
- Navigation layouts
- Reusable spacing and typography system

Using reusable templates helped create a scalable and uniform user experience across all screens.
